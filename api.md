###### upload()

###### Call Signature

> **upload**(`file`, `options?`): `Promise`\<[`WithMeta`](#withmeta)\<[`DocumentReceipt`](#documentreceipt)\>\>

Upload a PDF, DOCX, Markdown or text file (up to 25 MB). Answers 202. Free.

Pass a `File` and the name and media type come from it. Pass a `Blob`, a `Uint8Array` or an
`ArrayBuffer` and give `filename`. The media type is guessed from the extension when you give
none.

```ts
const receipt = await client.citationCheckDocuments.upload(file); // a File
const fromDisk = await client.citationCheckDocuments.upload(bytes, { filename: "brief.pdf" });
```

###### createFromFile()

> **createFromFile**(`file`, `options?`): `Promise`\<[`WithMeta`](#withmeta)\<[`CitationCheckRun`](#citationcheckrun)\>\>

Upload a file, wait until it is read, then check its citations. This is `upload`,
`waitUntilReady` and `create` in one call. The upload is free. The check costs 2 to 4 credits.

```ts
const run = await client.citationChecks.createFromFile(file, {
  wait: { timeout: 180, interval: 3 },
  reference_date: "2026-10-01",
});
assertComplete(run);
```

### Functions

#### callTool()

> **callTool**(`client`, `name`, `args`, `options?`): `Promise`\<`unknown`\>

Run one tool call and return a result that is safe to hand to a model.

- `getDecision` gets `max_chars` 4000 unless the call or `maxChars` says otherwise, and never
  more than `maxChars`.
- `getNorm` cuts the norm text to `maxChars` characters and sets `text_truncated` when it did.
- `checkCitations` returns a slim object: `id`, `status`, `verdict_counts`, `unique_citations`
  and, for each finding, `id`, `canonical`, `verdict`, `raw_text` and the two offsets. Read
  `status` before you trust the verdicts.
- A failure that comes from the API or the network returns `{ error: { code, detail,
  retry_after_seconds } }` instead of throwing, so the model can read it. Bad arguments and an
  unknown tool name return the same shape. Other errors, such as an abort, are thrown.
- With a `budget`, a call whose price does not fit is not sent and returns the error
  `budget_exceeded`. The cost of each answer is taken off `budget.credits`.
